# GitHub 注册指南

课程要用的东西都在 GitHub 上：LeRobot 的软件、SO-101 的打印文件、偃师造物每集的程序、电脑体检工具。这些仓库都是公开的，不注册也能看、也能下载。

注册之后多三件事：能在仓库里提问题，能在发新版本的时候收到邮件，能把用得上的仓库收藏起来下次好找。个人账号免费，注册五分钟。

## 二、注册

打开注册页，按屏幕上的顺序填：邮箱、密码、用户名、要不要收 GitHub 的推送邮件。已经有 Google 或者 Apple 账号的，点页面上的 Continue with Google 或 Continue with Apple 直接用它登录，不用另外设密码。

用户名会出现在你的主页地址里，别人看到的也是它，起一个自己长期用得下去的。

填完过一道人机验证，通常是拼一张图。然后 GitHub 往你填的邮箱发一个验证码，回邮箱取，填回页面。

## 三、把邮箱验证掉

验证码填对了，邮箱就算验证过了。这一步不能跳：邮箱没验证之前，GitHub 不让你建自己的仓库。

邮箱里没收到，先翻一遍垃圾邮件；还是没有，回 GitHub 的设置页里点重新发送。用公司邮箱注册的，有时候是公司的邮件网关把它拦了，换一个常用的个人邮箱更省事。

## 四、开两步验证

两步验证不开也能用，但账号被别人登进去之后，你提过的问题、收藏过的仓库都会挂在你名下被冒用，GitHub 自己也建议每个人都开。

在 Settings 里找 Access 这一组，点 Password and authentication 进去打开。第二把锁有四种选法：手机上的验证器 App、短信、硬件安全钥匙、GitHub 官方的手机 App。手机上装一个验证器 App 扫码是最常见的做法。

开的时候 GitHub 会给一组恢复码，存到自己找得到的地方。手机丢了、验证器 App 卸了，就靠这组码进账号。

## 五、注册完能做的三件事

### 下载代码

仓库页上有一个绿色的 Code 按钮，点开选 Download ZIP，整个仓库打成一个压缩包下下来。这条路不需要装任何东西，下完解压就能用。

会用 git 的直接克隆，以后一条 `git pull` 就能更新，不用重下：

```bash
git clone https://github.com/Yanshi-Robotics/Lets-Build-Robots-S1-SO101.git
```

### 提问题

上面这几个仓库都开着 Issues。进仓库页点 Issues，先翻一眼有没有人问过同样的事，没有就点 New issue 发一条新的。

写的时候把这四样带上：什么系统、跑的哪一条命令、屏幕上报了什么错、你已经试过什么。报错整段复制粘贴，比描述一遍准得多。偃师造物自己的两个仓库用中文写就行；LeRobot 和 SO-ARM100 是国外团队维护的，用英文提问回得快。

跑过电脑体检的，把 `report-latest.json` 一起贴上，维护仓库的人看这个文件就知道你电脑什么情况。

### 收更新

仓库页右上角有 Star 和 Watch 两个按钮。Star 是收藏，点了以后在自己的主页里能一眼找到这个仓库。Watch 是订阅，点开能挑通知的范围，只想在发新版本的时候收到邮件就挑那一档，不然仓库里每一条讨论都会给你发信。

## 六、常见问题答疑

页面打不开或者转半天：GitHub 的服务器在国外，中国大陆访问它时快时慢。多刷新几次，或者换一个网络试试，手机热点有时候比宽带通。

要花钱吗：个人账号免费，公开仓库随便建。收费的是私有仓库的高级功能和团队协作，看视频、下代码、提问题这些一分钱不花。

界面全是英文看不懂：登录后点右上角头像进 Settings，左边栏找 Appearance，里面有一项 Language，选简体中文。它只翻界面上的按钮和菜单，仓库里的说明文档和代码还是原文。

密码忘了：登录页上点 Forgot password，往注册邮箱发重置链接。开了两步验证又换了手机的，用第四节那组恢复码。

不注册行不行：能看、能用 Download ZIP 下代码，这两件不用账号。提问题、收藏、订阅更新这三件要账号。
