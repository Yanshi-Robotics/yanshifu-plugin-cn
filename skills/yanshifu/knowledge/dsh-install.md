# DeepSeek Harness 安装指南

DeepSeek Harness（命令名 `dsh`）是 DeepSeek 官方开源的智能体工具，和 Claude Code、Codex 是同一类东西：它跑在自己电脑上，你用中文说要干什么，它读你的文件、改代码、跑命令，做完把结果给你。

装它是四步：先装 Node.js，再用一条命令把 `dsh` 跑起来，然后去 DeepSeek 开放平台注册账号、建一把 API 密钥，最后把密钥填进 `dsh` 的设置页。网络正常的话全程二十分钟。

有一件事先说在前面：网页版和手机 App 的 DeepSeek 免费，`dsh` 走的是 API，按用掉的 token 计费，账户里得有余额才能用。价格在第四节。

官方把现在这个阶段写作开发者预览版，还会有不向后兼容的改动；这份资料对应 0.1.7-rc.2，群里以最新一版为准。

| 名称 | 网址 | 拿它做什么 |
|---|---|---|
| DeepSeek Harness 官方仓库 | https://github.com/deepseek-ai/deepseek-harness | 源码和最新说明；这个仓库关了 Issues，提问走它的 Discussions |
| DeepSeek Harness 官方文档 | https://deepseek-harness.github.io/deepseek-harness/ | 装好之后想调得更细看这里 |

官方只在两个地方发布 `dsh`：npm 上的 `@deepseek-ai/dsh`，和上面这个仓库。别的网站给的安装包不要下。

## 二、装 Node.js

`dsh` 是一个 Node 程序，电脑上没有 Node.js 就跑不起来。官方要求 22.19.0 以上的 22 版，或者 24 以上的任何版本；写这份资料的时候长期支持版是 24.21.0，装它正好。

版本不够的时候它不报错：Node 20 上实测过，屏幕上一个字都不打，直接回到提示符，退出码还是 0，看着像什么都没发生。所以先把这一步做扎实。

**Windows 10 / 11**

打开本资料开头链接表里的 Node.js 官网，点 LTS 那个按钮下载 `.msi` 安装包，双击，一路下一步。装完在开始菜单搜 PowerShell 打开，输入：

```powershell
node -v
```

**macOS**

同一个网站下载 `.pkg` 安装包，双击装完。打开「终端」，输入：

```bash
node -v
```

**Linux · Ubuntu**

发行版自带的太老，Ubuntu 24.04 的仓库里是 18.19.1，跑不了 `dsh`。用 nvm 装一个新的：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
source ~/.bashrc
nvm install 24
node -v
```

屏幕上打印出 `v24.21.0` 这样的版本号，Node.js 就装好了。

## 三、把 dsh 跑起来

先进到你想让它干活的那个文件夹，再启动：`dsh` 把启动时所在的目录当成默认工作区。桌面上有个 `demo` 文件夹想让它读，就先 `cd` 到 `demo` 里。

三个系统的命令一样：

```sh
npx @deepseek-ai/dsh web
```

`npx` 是 Node.js 自带的，它临时下载并运行，不用先安装。第一次要下几分钟，之后快得多。

命令跑起来之后，终端里会打印一条网址，浏览器自动打开它。默认地址是 `http://127.0.0.1:3080`，只有这台电脑上能访问。不想让它自动开浏览器，命令后面加 `--no-open`。

3080 这个号被别的程序占了就换一个：

```sh
npx @deepseek-ai/dsh --profile web --port 8080
```

浏览器里出现 `dsh` 的页面，这一步就算过了。天天用的话可以装成一个常驻命令，以后直接敲 `dsh web`：

```sh
npm install -g @deepseek-ai/dsh
```

## 四、注册账号，建一把 API 密钥

打开本资料开头链接表里的 DeepSeek 开放平台，用手机号或者邮箱注册，按页面提示验证。这个账号和网页版 DeepSeek 的账号是一套。

登录后进 API 密钥页，点创建，给它起个自己认得出的名字，比如「我的电脑」。密钥只显示这一次，关掉页面就再也看不到了，当场复制下来存到一个自己找得到的地方；弄丢了不要紧，回来删掉旧的重建一把。

密钥相当于账户的密码，谁拿到都能花你的钱。不要发到群里，不要写进代码传上 GitHub。

余额在控制台里看，不够就充值。2026 年 9 月的价格分尖峰和离峰两段，单位是元每百万 token，斜杠前是离峰价、后是尖峰价：

| 模型 | 输入 · 缓存命中 | 输入 · 缓存未命中 | 输出 |
|---|---|---|---|
| `deepseek-flash` | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| `deepseek-v4-pro` | 0.15 / 0.30 | 4.5 / 9.0 | 13.5 / 27.0 |

`deepseek-flash` 便宜，问答和改小段代码够用；`deepseek-v4-pro` 贵，让它自己读一整个项目、连着改十几个文件的时候差别看得出来。先充一小笔用几天，看自己实际花多少，再决定往里放多少。

## 五、把密钥填进 dsh

`dsh` 没有账号登录这一说，它认的是密钥：填进去就能用，删掉就用不了。

在浏览器里打开 `dsh` 的页面，进「设置 → 模型」，DeepSeek 卡片上有一个 API 密钥字段，把刚才那串粘进去保存。保存之后页面上只剩一段打了码的描述，看不到明文了；密钥本身存在配置目录里，Linux 上实测是 `~/.dsh/.credentials.yaml`。改模型设置不用重启，下一次提问就生效。

接着点「选择工作区」，把第三节启动 `dsh` 时所在的那个目录加进来并选中。没选工作区之前，输入框是用不了的。

再在模型选择器里选一个模型，选中的同时它也成了以后新会话的默认模型。

现在可以发第一句话了，比如「把这个目录里有什么讲一遍」。它要读文件、改文件或者跑命令的时候，会先弹出来问你同不同意，你点了才动手。

## 六、常见问题答疑

输入 `node -v` 说找不到这个命令：装完没重开终端，旧窗口里还是旧环境。关掉窗口重新打开一个。

跑完 `npx` 那条命令，屏幕什么都不打就回到提示符：Node 版本太低。回第二节看 `node -v` 打出来的是不是 22.19.0 以上的 22 版或者 24 以上。

浏览器打开是空白页，或者显示 401：`dsh` 的网址带一条一次性令牌，手敲地址、从收藏夹或者旧的历史记录进去都会被挡。用终端里打印的那条完整网址，整条复制。

第一次下载很慢：`npx` 从 npm 拉包，中国大陆的网络有时候慢。挂着等，或者换个时间再跑，下到一半断了重跑不会从头下。

想把它删干净：配置、会话记录和密钥都在用户目录下的 `.dsh` 文件夹里，删掉它就干净了。用 `npm install -g` 装过的，再跑一次 `npm uninstall -g @deepseek-ai/dsh`。

它会不会把我的文件传出去：`dsh` 跑在自己电脑上，但你让它读的内容会作为提问的一部分发给 DeepSeek 的服务器，这是它能干活的前提。公司代码和私人资料要不要给它读，自己先想清楚。
